# 1. Преобразование Барроуза-Уиллера

## Общая идея

* Построить все циклические сдвиги входной строки
* Отсортировать перестановки в порядке
* Взять последний столбец как выходную строку и зафиксировать на какой строке после сортировки оказалась входная строка

## Детали реализации

### Encode

Пусть `block` - исходная строка для обработки, а `n` кол-во символов в этой строке . Тогда

1. Инициализируем неотсортированный массив всех сдвигов `rotations`, где элемент на позиции `i` обозначает кол-во
   совершенных циклических сдвигов

```kotlin
val rotations = Array(n) { it } // 0, 1, 2, ... , n-1
```

2. Для сортировки массива не будем строить строку полностью. Чтобы лексикографически сравнить строку сдвинутую `A` раз и
   `B` раз достаточно найти наименьшее число `offset` для которого
   `block[(startA + offset) % n] != block[(startB + offset) % n]`
3. После сортировки массива `rotations` вычисляем последнюю букву в каждой перестановке. Если перестановка началась с
   индекса `A`, то очевидно, последний символ можно вычислить как `A-1`

```kotlin
val start = rotations[i]
val lastPos = if (start == 0) n - 1 else start - 1
result[i] = block[lastPos]
```

### Decode

Мы пониманием, что полученная закодированная строка при сортировке даст первый столбец в исходной матрице. Пусть первый
столбец будет `first`, а последний `last`

1. Считаем сколько раз каждый символ встречается в закодированной строке. `count[i]` - сколько раз байт `i` встречается
   в строке
2. Строим массив `starts`, что-то вроде префиксных сумм частот.
3. Для каждого символа в `last` пытаемся понять, какой позиции в `first` он соответствует. Идём слева направо
    * Берем `last[i]`. Пусть `last[i]` уже встретился `m` раз
    * тогда в строке `first` этот символ встретится на позиции `starts[last[i]]` + `m`
    * увеличиваем `m`

```kotlin
val occurrenceCount = IntArray(256) // типо хэш-таблицы - счётчик, сколько раз мы встретили символ i
val next = IntArray(n)
for (i in 0 until n) {
    val c = transformed[i].toUnsignedByte()
    next[i] = starts[c] + occurrenceCount[c]
    occurrenceCount[c]++
}
```

4. Имея связки пытаемся восстановить исходную строку.
    * Берём номер строки, который был закодирован вместе с последовательностью и бежим справа налево (т.к на предыдущем
      шанге вычислили обратные переходы), пусть будет `i`
    * Берём `last[i]`, это и будет последний символ
    * Следующий индекс берём из next[i]
    * `last[next[i]]` - предпоследний символ, `last[next[next[i]]]` - 2-ой с конца символ и т.д

# 2. Стопка книг

### Encode
1. Инициализируем алфавит (стопку) символами от 0 до 255
2. Для каждого символа в исходной строке
   * Ищем текущую позицию в 'стопке'
   * Переносим символ в начало стопки
3. Т.к символы в стопке каждый раз двигаются, то позиция в стопке и будет показывать, сколько различных символов встретилось между двумя одинаковыми

### Decode
Работает как encode в обратном порядке
1. Инициализируем алфавит (стопку) символами от 0 до 255
2. Считываем позицию символа из закодированной строки
3. Берем символ на этой позиции в текущей стопке и переносим его в начало

# 3. Построение кода Хаффмана

### Encode
1. Заполняем счётчик частот на основе массива входящих байтов
2. Строим дерево
   * Кладём символы и их частоты в приоритетную очередь
   * Два узнала с минимальными частотами объединяем в один
3. Строим коды. Шаг 'в лево' по дереву - 0. Шаг 'в право' - 1
   * Т.к работает с битами, а не байтами, то есть необходимость добивать размер байта нулями. Чтобы корректно декордировать, фиксируем эту информацию в `bitLength`
4. В файл пишем информацию о `bitLength`, размер закодированного блока, массив частот (чтобы восстановить дерево), закодированную последовательность бит

### Decode
1. Строим дерево на основании массива частот
2. Читаем биты, фиксируем путь в дереве. При достижении листа фиксиурем символ и возвращаемся к руту дерева.
